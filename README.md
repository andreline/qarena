# QArena: o playground dos QAs

Ambiente de treino para QAs praticarem testes manuais, testes exploratórios e bug report em uma loja fictícia com bugs plantados de propósito.

Projeto educacional criado por Andreline Lira, parte do ecossistema QA do Zero.

Ambiente fictício. Todos os dados, produtos e pedidos são simulados para fins de estudo.

## Stack

Vite, React 19, TypeScript, Tailwind CSS v4, React Router v7, Zustand.

## Rodando localmente

```bash
npm install
npm run dev
```

Este projeto é 100% front-end. Não existe backend, banco de dados ou autenticação real, tudo funciona no navegador.
